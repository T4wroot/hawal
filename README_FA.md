# ⚡ تانل هه‌واڵ (Hawal Tunnel)

> **پنل مدیریت تانل هوشمند، مدرن و فوق‌سریع بدون وابستگی با هسته مالتی‌پلکسینگ برای دورزدن محدودیت‌های اینترنت**

*کلمه «هه‌واڵ» (Hawal) در زبان کردی به معنای **دوست، رفیق و همراه** است.*

---

## 🌟 چرا تانل هه‌واڵ؟

برخلاف اسکریپت‌های سنتی که دچار باگ تداخل پورت‌ها، پردازش‌های زامبی (Zombie Processes)، مصرف سنگین منابع یا خطاهای همگام‌سازی فایل‌ها هستند، **هه‌واڵ (Hawal)** یک سیستم سبک، بدون وابستگی و فوق‌العاده پایدار را فراهم می‌کند.

---

## ✨ قابلیت‌های کلیدی

* 🚀 **بدون نیاز به پیش‌نیاز (Zero-Dependency):** اجرای آنی بدون نیاز به نصب پکیج‌های پایتون (`pip`)، بیلد‌های نودجی‌اس یا دیتابیس‌های حجیم.
* ⚡ **نصب تک‌خطی فوق‌سریع:**
  * نصب کامل کنترل پنل با یک دستور در کمتر از ۵ ثانیه.
  * اتصال نودهای جدید (ایران و خارج) با یک دستور تک‌خطی (`curl ... | bash` یا `docker run`).
* 🏷️ **مدیریت تگی و تعاملی پورت‌ها:** افزودن چندین پورت (443, 2083, 8080, ...) با کلید `Enter` یا دکمه‌های آماده، بدون تداخل با پورت ترانسپورت.
* 🌍 **تشخیص خودکار کشور و پرچم (Smart GeoIP):** شناسایی خودکار موقعیت سرور بر اساس IP (🇩🇪 آلمان، 🇫🇮 فنلاند، 🇳🇱 هلند، 🇮🇷 ایران، 🇹🇷 ترکیه، 🇫🇷 فرانسه، 🇺🇸 آمریکا و...).
* 📊 **توپولوژی زنده و تست پینگ بین سرورها:** نمایش انیمیشنی مسیر اتصال و پایش تاخیر و پکت‌لاس بین سرورها به صورت لحظه‌ای.
* 🛡️ **پروتکل‌های ترانسپورت ضد فیلتر:** پشتیبانی از حالت‌های `WebSocket`، `TCP`، `TCPMux` و `TLS` برای رفع افت سرعت آپلود و تراتلینگ.
* 🐳 **پشتیبانی همزمان از داکر و لینوکس سرویس (Systemd):** تولید خودکار فایل `docker-compose.yml` و سرویس‌های سیستمی.

## 🚀 راهنمای نصب و راه‌اندازی سریع

### ۱. نصب کنترل پنل هه‌واڵ (روی سرور اصلی)

دستور زیر را در ترمینال سرور خود اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/T4wroot/hawal/master/install-panel.sh | bash
```

پس از اتمام، پنل روی آدرس زیر در دسترس خواهد بود:
👉 `http://SERVER_IP:9090`

---

### ۲. اتصال سرورها (نود ایران یا خارج)

1. وارد پنل شده و به بخش **مدیریت نودها (سرورها)** بروید.
2. روی **+ افزودن نود جدید** کلیک کرده و نام و IP سرور را وارد کنید.
3. دستور تک‌خطی تولید شده را کپی کرده و روی سرور مقصد اجرا نمایید:

```bash
# نمونه دستور تولید شده در پنل:
curl -fsSL "http://PANEL_IP:9090/install?token=TOKEN&role=kharej&name=Germany-Core" | bash
```

نود ظرف کمتر از ۳ ثانیه در پنل آنلاین و شناسایی می‌شود!

---

### ۳. اجرا از طریق داکر (Docker Compose)

```bash
git clone https://github.com/T4wroot/hawal.git
cd hawal
docker compose up -d
```
